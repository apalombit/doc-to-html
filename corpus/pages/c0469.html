3 Parameter reference, Sycamore 200 drive controller

Groups P1 to P4. Values are factory settings unless a commissioning sheet says otherwise.

Document: GC-SY2-PRM
Revision: C
Firmware: 3.2.1
Issued: 06/08/2022
Applies to: SY2-0075 to SY2-0900
Language: English (UK)
Change P1 values only with the drive stopped and the enable input open. A write while running is refused with fault E14.

Parameter numbers follow the pattern Pg.nn, where g is the group and nn the item. Ranges are inclusive. Thermal values1 are held in non-volatile memory, while ramp rounding2 and the earth-fault limit3 take effect at the next start command.
