Change one parameter at a time. Hold the SET key for three seconds to enter the menu, select the number with the arrows, then press SET again to store the value. The controller returns to the run display after sixty seconds without a key press.


3.3 Commissioning checks

☑ Supply isolated before opening the cover
☑ Earth bond measured below 0.1 ohm
☑ Probe leads kept away from mains cables
☐ Alarm contact tested with the siren
☐ Parameters recorded in the site log
☐ Customer shown the manual reset

WARNING. Mains voltage is present on terminals T1 to T4 even when the pump is stopped. Isolate at the consumer unit before any work.
